# 三澄製氷 公式サイト（架空の会社）

東京・墨田の製氷会社「三澄製氷」の公式サイトです。会社も、住所・電話番号・価格・取引先の声も、すべて架空です。

- デザインの方針：`DESIGN.md`
- 素材の出どころとライセンス：`ASSETS.md`

## 動かし方

```sh
npm install
npm run dev      # 開発用。http://localhost:5173
npm run build    # dist/ に書き出す
npm run preview  # 書き出したものを確認する
```

`dist/` の中身をそのままサーバーに置けば公開できます（相対パスで書き出しています）。ただし `404.html` の中のリンクだけは、公開先の `/misumi-seihyo/` に合わせた絶対パスです。置き場所を変えるときは書き換えてください。

公開先は https://kokonao1111.github.io/misumi-seihyo/ です。`main` に push すると、GitHub Actions が自動で公開し直します。

## 構成

| 場所 | 内容 |
|---|---|
| `index.html`、`junpyo/index.html` など | 各ページの本文 |
| `src/partials/` | 全ページ共通の部品（head、ヘッダー、フッター） |
| `vite.config.js` | 共通部品を差し込む仕組みと、ページの一覧 |
| `src/style.css` | 見た目 |
| `src/main.js` | スクロール連動、メニュー、表、フォーム、フッターの溶け時計 |
| `src/ice/stage.js` | 氷の3D（形、置き場所、色の切り替え） |
| `src/ice/shaders.js` | 氷の屈折シェーダー |
| `public/` | 画像、アイコン、404ページ |
| `tools/still.html` | 静止画の書き出し用ページ（開発専用。ビルドには含まれません） |
| `scripts/` | 素材の取得、画像変換、静止画の書き出し、画面確認、リンクの点検 |

### ページを足すとき

1. `新しい名前/index.html` を作り、先頭に `<!--page {...} -->` を書きます。ほかのページを写すのが早いです。
2. `vite.config.js` の `PAGES` に足します。
3. `src/partials/header.html` と `footer.html` にリンクを足します。
4. `npm run build` のあと `node scripts/check-links.mjs` で、リンク切れがないか確かめます。

## 3Dの切り替え

- WebGLが使えない端末では、3Dの代わりに静止画を表示します。`?noice` をURLにつけると、この表示を確認できます。
- 「視差効果を減らす」設定の端末では、氷の自転となめらかなスクロールを止め、スクロールしたときだけ描画します。
- スマホや性能の低い端末では、解像度を落として描画します。

## 本番で差し替えるもの

- お問い合わせフォームは見本です。送信ボタンを押しても、どこにも送られません。
- 住所、電話番号、価格、便の時刻、取引先の声は架空です。
